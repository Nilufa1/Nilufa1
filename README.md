# Face Mask Detection System

This repository contains a deep learning system developed in Python using TensorFlow, Keras, and OpenCV to detect whether people are wearing face masks in real-time.

## Features
- **Model Architecture**: MobileNetV2 base network fine-tuned on custom facial datasets.
- **Image Processing**: Dynamic loading, resizing, and array transformation for dataset normalization.
- **Inference Options**: Supports analysis on static images or smooth real-time video tracking using a smartphone connected via USB as a webcam.

## Dataset Acknowledgement
The underlying images used to train this model were sourced directly from Kaggle. Due to repository size constraints, the raw dataset assets are excluded from this source tree.
